# 🧩 UNOFFICIAL Palladium Universal Game System


A flexible, modern Foundry VTT system for running Palladium-style games

🚀 Overview

The UNOFFICIAL Palladium Universal Game System is a fully customizable Foundry VTT system designed to support the wide range of games built on the classic Palladium engine.

Whether you're running:

post-apocalyptic sci-fi
fantasy adventures
superhero campaigns
mutant animal chaos
or multi-genre crossovers

…this system provides a single unified character sheet and rules framework to handle it all.

🔧 Designed Philosophy

This system intentionally follows a core principle:

Palladium is not rigid — your system shouldn't be either.

Instead of enforcing strict automation, this system:

supports manual play styles
allows house rules
adapts to any Palladium variant
